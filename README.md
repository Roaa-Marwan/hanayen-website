# Hanayen Restaurant Website

موقع عربي RTL ثابت وسريع لمطاعم وشاورما الحناين.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل أي static server من داخل المجلد.

مثال:

```bash
python3 -m http.server 8080
```

ثم افتح:

`http://localhost:8080`

## الملفات

- `index.html` — هيكل الموقع والمحتوى.
- `styles.css` — التصميم، الاستجابة للموبايل، والأنيميشنز.
- `script.js` — المينيو للموبايل، ظهور العناصر، lightbox، tilt effect.
- `assets/` — صور المستخدم الأصلية + نسخ مقصوصة ومحسنة للاستخدام داخل الموقع.

## قبل النشر الرسمي

- راجع الأسعار لأنها مأخوذة من صورة القائمة المرفقة وقد تتغير.
- راجع رقم التقييم وعدد المراجعات لأنه مأخوذ من لقطة Google المرفقة.
- يفضّل إضافة روابط Google Maps الرسمية لكل فرع بدل روابط البحث العامة.
